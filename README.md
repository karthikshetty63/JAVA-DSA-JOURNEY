## 🚀 How to Use

1. **Navigate to topic folder**:
   ```bash
   cd src/basics
   ```

2. **Compile Java file**:
   ```bash
   javac FileName.java
   ```

3. **Run the program**:
   ```bash
   java FileName
   ```

4. **Study the code** and understand the concepts
